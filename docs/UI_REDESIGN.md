# 创作工作台 UI

本次重设计以每日处理日报为主线：蓝紫渐变、珊瑚橙点缀、真实作品卡片，以及保留群列表的右侧日报工作区。采用现有 React / TypeScript / Vite，不新增服务或数据库迁移。

## 信息结构

| 导航 | 主要用途 |
| --- | --- |
| 今日工作台 | 日期、完成情况、待处理事项、日报卡片 |
| 日报作品 | 直接进入日报工作区、图片风格、排行榜模板；画廊位于次级入口 |
| 群聊管理 | 群绑定、配置、停启用、测试读取、回收站入口 |
| 运行任务 | 运行阶段、日志、历史恢复、任务详情 |
| 消息归档 | 聊天记录、历史归档与回收站 |
| 设置 | 运行配置、系统健康、启动检查、恢复信息 |

日报作品默认选择当前列表的首份日报并打开共享 `ReportWorkspace`，通过替换 URL 而非新增历史记录保留正常后退行为；没有匹配日报时保持空状态。画廊通过右上角「浏览画廊」进入，作品点击直接返回对应日报工作区。日期筛选与当前日报日期分别保存，查看所有日期时切换日报仍保留完整列表。今日工作台的日报卡片也打开共享 `ReportWorkspace`。预览、图片与提示词、运行详情共享同一运行身份；生成、发送和人工核对由 `ReportActions` 承接。工作区底栏固定操作，确认弹窗通过 Portal 显示在全屏层。

## 状态与兼容

- Hash 路由参数 `date`、`group`、`panel` 表示运行日期、后端归档群名和工作区标签；`view` 表示画廊 / 风格 / 模板，`section` 表示设置区域。作品页的 `collectionDate` 用于关闭工作区后恢复原日期筛选。
- 详情和文件沿用后端 `group_name + run_date` 路径；写操作沿用数值群 ID 与运行日期。明确指定的日报不存在时，不能自动改选另一群。
- 旧 `ranking`、`images`、`templates`、`history`、`system` 入口仍可访问对应内容。
- 新图审核、发送结果未知、Prompt 版本检查、候选图片认领、历史恢复确认均保留原后端协议。保存 Prompt 不触发生图或发送；请求已接受不等于已完成。
- 草稿有未保存修改时，离开工作区或页面会询问是否丢弃。操作提交中保护目标身份；生成期间禁止修改正在使用的提示词。浏览器关闭或刷新保留原生离开提醒。
- 当前版本针对电脑验收，覆盖 1280、1440、1920 宽度；小屏保留基本可用布局。支持键盘焦点及减少动态效果。

## 验证方式

在 `frontend` 目录运行 `npm test`、`npm run build` 和 `npm run test:e2e`。浏览器测试使用拦截的 Fake API，不连接生产发送器。验收重点包括：

1. 首页没有展开的运行日志，打开日报后可在同一工作区预览排行榜与图片。
2. 日期、群与标签可通过 URL 恢复；群切换不串内容，关闭后恢复原筛选及浏览位置。
3. 发送确认之前没有发送请求；人工核对只写检查点；已发送诊断图仍展示发送事实且不能重发。
4. 草稿取消离开后保留，保存携带版本号且不触发生图或微信发送。
5. 原有图片主题选择、批量部分失败重试、恢复清单和批量文件读取继续可用。
