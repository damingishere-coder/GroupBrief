# 内部 V2 路线摘要

`V2` 是内部模块和开发路线代号。GroupBrief 的首个公开产品版本仍为 `v1.0.0`，不会为了展示而重命名现有 `/api/v2` 路由、数据库字段或代码目录。

## 已纳入 v1.0.0

- 统一的运行目录和状态文件。
- 群聊配置、任务执行、排行榜、Prompt、图片与归档页面。
- 独立群调度、失败隔离和恢复保护。
- 可选邮件和默认关闭的微信发送适配器。

## 后续优先事项

- 建立可重复的真实 Codex 生图验收。
- 按微信客户端版本记录读取和发送兼容结果。
- 完善发送前确认、恢复诊断和隐私审计。
- 在有真实需求时再扩展贡献模板和文档站。

详细实现与当前限制以 [`README.md`](../../README.md) 和 [`CHANGELOG.md`](../../CHANGELOG.md) 为准。
