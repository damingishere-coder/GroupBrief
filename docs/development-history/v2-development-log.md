# 内部 V2 开发记录摘要

`V2` 是代码和开发阶段使用的内部代号，不代表当前公开产品版本。公开版本统一为 `v1.0.0`。

该阶段在原有日报闭环上增加了：

- 按群、按日期保存的运行状态机。
- Dashboard、群聊与任务、排行榜、AI 图片和归档页面。
- Codex 摘要与生图 Prompt 工作流，DeepSeek 可选备用。
- 图片主题、Prompt 编辑、重新生成和发送前复核。
- 微信发送状态保护、失败恢复和防重复机制。

微信发送相关代码和 Mock 测试已经存在，但真实微信版本、已登录桌面、OCR 和窗口兼容性的可重复端到端验收尚未完成，因此默认关闭。

原始开发日志中的真实群名、群 ID、成员昵称、消息内容、统计和本机诊断已从当前公开版本移除。
