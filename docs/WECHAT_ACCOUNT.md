# 微信发送账号头像核验

Windows 微信 4.x 的原生发送器必须先绑定账号头像。双开时按固定头像选择窗口，再核验目标群；不按窗口顺序或前台位置选择。

在“设置中心 → 运行设置 → 微信发送账号”点击“扫描微信头像”，选择左上角属于发送账号的头像，填写账号名称并点击“确认绑定所选头像”。页面显示保存的标准头像和当前核验结果。“仅核验账号”不会发送消息。

未绑定、标准图损坏、任一微信候选头像无法读取、零个或多个窗口匹配、锁屏时，发送器停止。已有最小化或托盘窗口可在扫描或发送前恢复，但不会启动新微信或处理登录。查看设置和健康状态不会主动恢复窗口。

每条文字和图片在粘贴前及按 Enter 前重新检查账号、前台窗口和目标群。失败时不按 Enter、不清除草稿；已成功发送的文字保持原有回执，图片失败不导致整包重发。

标准头像存放在数据库同目录的 `wechat-account/<sha256>.png`，绑定记录保存在现有设置表。重新绑定保留旧标准图；通用设置 API 不能修改绑定记录。已绑定时禁止切换到不支持头像核验的旧发送器。

头像裁剪使用微信 4.x 主窗口左侧固定位置，按窗口 DPI 缩放，通过 PrintWindow 读取窗口自身画面。图像归一化为 64×64，排除圆角边缘，同时要求 64 位差分哈希距离不超过 4、有效区域 RGB 平均绝对误差不超过 0.045。阈值固定，不在失败后自动放宽。

接口位于 `/api/wechat-sender/account`：GET 查看标准头像和当前状态，POST `/candidates` 扫描预览，PUT `/binding` 用候选 ID 和账号名称确认绑定，POST `/verify` 仅核验账号。预览五分钟后失效；绑定时重新检查窗口进程身份及头像。现有群目标核验接口包含账号核验。
